# FreeNet Group - موقع وبوابة المبيعات

مشروع متكامل ومبسط لإدارة طلبات ومبيعات باقات شبكات المحمول (فودافون، اتصالات، WE) مع التوجيه المباشر للواتساب ولوحة تحكم مدمجة لتخزين البيانات والتقارير.

## 🌟 المميزات
- **بدون مصاريف تشغيل:** يعمل 100% بشكل مجاني على GitHub Pages.
- **توجيه مباشر للواتساب:** يتم إرسال الطلبات إلى الرقم `01001621853` بتنسيق ممتاز.
- **لوحة تحكم مدمجة:** تخزين محلي (Local Storage) لأرقام الباسوردات والعملاء ونوع الاشتراكات (فردي 28 يوم / أصحاب 32 يوم).
- **تقارير المبيعات:** معرفة إجمالي الطلبات والأكثر مبيعاً تلقائياً.

## 🚀 طريقة الرفع على GitHub
1. قم بإنشاء مستودع جديد (New Repository) على حسابك في GitHub.
2. قم برفع ملف `index.html` و `README.md`.
3. اذهب إلى **Settings** > **Pages**.
4. اختار الفرع **main** ثم اضغط **Save**.
5. رابط موقعك سيعمل مباشرة خلال ثوانٍ!
